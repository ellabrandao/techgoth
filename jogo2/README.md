# TECHGOTH SPACE IMPACT.exe
Jogo arcade em JavaScript puro + Canvas, inspirado em Space Impact e com sprites do TECHGOTH RUN.

## Rodar
Abra `index.html` no navegador (ou publique a pasta na raiz do GitHub Pages).

## Controles
- WASD / setas: mover
- Espaço: atirar (segure)
- P: pausar
- M: alternar som (reservado)
- Toque/arraste no mobile: mover e atirar

O jogo é independente e não altera o TECHGOTH RUN original.
